## sobre mim

Sou o Fishixz (Luis), desenvolvedor independente e builder de software. Minha forma de aprender é transformar uma ideia em algo que roda de verdade: interface, API, dados, integração, automação, deploy e manutenção.

Gosto de mexer em tudo e entender como as peças se conectam. Por isso, meus projetos vão de páginas web e protótipos rápidos a bots, plataformas educacionais, clientes Android, gamemodes SA-MP/open.mp, plugins nativos e ferramentas de infraestrutura.

Não sigo uma única stack. Escolho a ferramenta pelo problema e uso cada projeto como um laboratório para aprender, testar hipóteses e entregar uma experiência melhor.

## o que eu construo

- **Sistemas conectados:** Android, SA-MP/open.mp, C/C++, NDK, Pawn, Discord e integrações que precisam conversar entre si.
- **Produtos web full-stack:** React, Next.js, Vite, TanStack, TypeScript, Supabase, Drizzle e bancos locais ou remotos.
- **IA e automação:** APIs, jobs, filas, cache, bots, clientes Python/FastAPI, Playwright e fluxos orientados por dados.
- **Experiências de produto:** interfaces responsivas, painéis, WebViews, cards dinâmicos, ferramentas de estudo e protótipos que resolvem problemas reais.

## como eu penso

Gosto de trabalhar perto do problema e perto da implementação. Normalmente começo pelo fluxo que a pessoa precisa, crio uma primeira versão, observo onde ela quebra e vou conectando as camadas até o sistema ficar útil, confiável e fácil de evoluir.

```text
problem  →  prototype  →  integration  →  validation  →  polish
```

A parte mais divertida, para mim, é quando uma ideia deixa de ser só uma tela e vira um sistema inteiro: com estado, regras, dados, automações e uma experiência que faz sentido.
